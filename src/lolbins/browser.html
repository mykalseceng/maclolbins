      What the glyphs mean

      • Catalogued LOLBin. Listed in the catalogue with abuse notes and worked commands.
      • Setuid. Runs as its owner (usually root) whoever starts it.
      • Setgid. Runs with its group's privileges.
      • Private entitlements. Holds Apple-internal, TCC, SIP or task-port keys.
      • Entitlements. Holds only public entitlement keys.
      • TCC grant. This Mac's privacy database allows it a protected service, such as Full Disk Access.
      • TCC entitlements. Reaches protected services by entitlement, without a prompt.
      • Weakened runtime. Holds an entitlement that lets other code be injected into it or attach to it.
      • XPC server candidate. launchd registers a Mach service for this executable and the scan found static listener evidence. Reachability and authorization are not tested.
      • Script. Interpreted text; scripts carry no code signature.
      • Unsigned. Shown on rows only for unsigned files that aren't scripts.
      • Developer tools shim. Forwards to Xcode tools when they're installed.
      • Unreadable. The scan couldn't read the file, so its signature and hash are unknown.
      • Symbolic link. The path points to a file elsewhere on disk.
